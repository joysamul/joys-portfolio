## EmailJS Contact Form

The contact form uses the EmailJS browser SDK. To enable delivery:

1. Create an EmailJS email service and a template. Set the template recipient to `joysamul9933@gmail.com` and use the form variables `{{name}}`, `{{email}}`, and `{{message}}`.
2. Copy `.env.example` to `.env.local` and replace the placeholder values with the Service ID, Template ID, and Public Key from your EmailJS account.
3. Restart the Next.js development server after editing `.env.local`.

Only the EmailJS public key belongs in `NEXT_PUBLIC_EMAILJS_PUBLIC_KEY`. Do not put an EmailJS private key in a browser environment variable.

You can start editing the page by modifying `app/page.js`. The page auto-updates as you edit the file.
